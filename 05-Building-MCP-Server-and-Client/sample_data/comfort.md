# Temperature Comfort Index

- Below 10°C: Cold. Heavy coats and thermal wear recommended.
- 10°C to 17°C: Mild/Cool. Light jackets or jumpers recommended.
- 18°C to 25°C: Comfortable. Standard casual clothing suitable.
- 26°C to 32°C: Warm. Breathable fabrics, sunglasses and sun protection.
- Above 32°C: Very hot. Heat precautions and sun avoidance advised.
