# TAFE new-student orientation

This fictional classroom plan uses two locations to test the same weather rule. Each session starts at 10 am local time and runs for one hour.

| City | Outdoor venue | Indoor backup |
|---|---|---|
| Perth | Campus courtyard | Learning Hub, Room P2 |
| Sydney | Campus courtyard | Student Centre, Room S3 |

- If the weather report indicates rain, move to the listed indoor venue and offer a Microsoft Teams option. Keep the start time.
- Otherwise, keep the outdoor venue.
- For an indoor notice, explain that online attendees should use the organiser's meeting invitation. The organiser must confirm whether attendees without a TAFE account can join. This sample contains no meeting link.
